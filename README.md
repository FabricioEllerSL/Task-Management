# 🗂️ Task Management

This project is a learning exercise built with **FastAPI**, designed to help me improve my backend development skills.  
It provides a simple RESTful API for managing tasks — including creating, reading, updating, and deleting them.

In the future, I plan to add a **front-end using Vue.js** to enhance the user experience and continue developing my full-stack skills.

---

## 🛠️ Tech Stack
- **Backend:** FastAPI (Python)
- **Database:** MongoDB (via Motor)
- **Frontend (planned):** Vue.js

---

## 🚀 Goals
- Improve my understanding of **FastAPI** and asynchronous programming in Python  
- Practice building a **complete CRUD API** connected to a NoSQL database  
- Expand the project with a **Vue.js interface** for task management  

---

## 📦 Future Improvements
- Add user authentication (JWT)
- Implement task filtering and sorting
- Containerize the project using Docker.
- Create a responsive UI with Vue and something else like Tailwind CSS or Vuetify

This repository is mainly for **educational purposes**, helping me explore FastAPI concepts such as:
